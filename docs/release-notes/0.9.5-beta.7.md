## Version de test (canal Bêta)

Tu la reçois parce que tu as choisi **Paramètres › À propos › Canal › Bêta**.

## Changements

- **Bibliothèque** refaite dans le style « Écran console » :
  - en haut, **Ta bibliothèque** avec le nombre de jeux installés et de jeux sur ton compte Steam ;
  - le **nom du jeu en entier** sous la jaquette (deux lignes au plus), avec le store et ton temps de jeu, plus rien posé sur l'image ;
  - les jeux installés d'abord, puis une section **Pas installés sur ce PC** ;
  - le bouton **Installer** n'apparaît qu'au survol de la jaquette ;
  - les **logiciels** (Wallpaper Engine, Blender, SteamVR…) et les entrées sans nom ne sont plus affichés. Avec ta clé Steam Web API, Player X reconnaît tous les logiciels du magasin Steam.
- **Accueil** : le bouton **Jouer** prend le style du bouton Télécharger du site (bordure aux couleurs de Player X qui tourne, halo au survol).
