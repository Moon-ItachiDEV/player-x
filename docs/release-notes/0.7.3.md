## Nouveautés

- **Trophées** : une nouvelle page dans le menu avec tous tes succès Steam. Tu y trouves tes succès débloqués, tes jeux à 100 %, ta complétion moyenne, ton niveau Steam, tes derniers succès, tes plus rares et ta progression jeu par jeu. Un clic ouvre la fiche du jeu. La première lecture prend quelques minutes, les suivantes ne relisent que les jeux joués depuis.
- **Succès dans la fiche** : chaque jeu Steam montre ta progression, tes 3 succès les plus rares et le dernier débloqué. « Voir tous les succès » ouvre la liste complète, à filtrer et à trier, avec la rareté (part des joueurs qui l'ont). Les succès cachés restent masqués jusqu'au clic sur « Révéler ».

Les succès viennent de ton compte Steam, avec la clé Steam Web API déjà utilisée pour tes amis et ta bibliothèque. Ton profil Steam doit avoir « Visibilité sur mes jeux » sur « tout le monde ». Les jeux Epic et EA n'ont pas de succès dans Player X : ces stores ne les partagent pas.

## Installer

Télécharge `Player-X-Setup-0.7.3.exe` ci-dessous. Windows SmartScreen peut afficher un avertissement (installeur non signé par Microsoft) : **Informations complémentaires** puis **Exécuter quand même**.

Si tu as déjà la 0.4.0 ou plus récente, rien à faire : la mise à jour arrive toute seule.
