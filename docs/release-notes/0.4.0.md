## Nouveautés

- **Écran de démarrage** : Player X analyse ton PC (Steam, Epic Games, EA app), puis tu choisis tes jeux favoris en grand. Tu peux le rouvrir dans Paramètres › Bibliothèque › « Choisir mes jeux favoris ».
- **Mises à jour automatiques** : Player X vérifie les nouvelles versions au démarrage puis toutes les 6 heures, les télécharge en arrière-plan et les installe au redémarrage. Tout est dans Paramètres › À propos.

## Corrections

- Discord connecté sans serveur : la carte affiche « Connecté », le serveur (widget) devient une option.
- Widget Discord : Player X interroge Discord comme un navigateur et affiche la vraie cause d'une erreur (widget désactivé, serveur introuvable, trop de requêtes). Le lien « JSON API » peut remplacer l'identifiant du serveur.
- Steam : ton pseudo et ton avatar s'affichent même si tu as ajouté la clé Steam Web API après t'être connecté.
- Anneau de focus visible sur les boutons principaux au clavier.

## Installer

Télécharge `Player-X-Setup-0.4.0.exe` ci-dessous. Windows SmartScreen peut afficher un avertissement (installeur non signé) : **Informations complémentaires** puis **Exécuter quand même**.

Les versions 0.3.0 et plus anciennes n'ont pas de mise à jour automatique : installe la 0.4.0 une fois, les suivantes arriveront toutes seules.
