## Version de test (canal Bêta)

Tu la reçois parce que tu as choisi **Paramètres › À propos › Canal › Bêta**.

## Changements

- **Actus**, refaite dans le style de l'Accueil :
  - la dernière annonce s'affiche en grand en haut : son image en plein écran sous la barre du haut, le nom du jeu en très grand, le titre dessous et le bouton **Lire le patch**. Plus rien ne cache la bannière de l'annonce ;
  - dessous, **Tes jeux** : chaque jeu une seule fois, avec sa jaquette et ses dernières annonces, sans le nom du jeu répété dans les titres ;
  - clic sur une jaquette : seulement ce jeu ; **Tous tes jeux** pour revenir ;
  - **Patchs**, **Toutes les actus**, **Tout marquer comme lu** et **Actualiser** restent en haut quand tu fais défiler.
