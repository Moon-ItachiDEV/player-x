## Nouveautés

- **Temps de jeu** : Player X compte tes heures sur chaque jeu, même lancé hors du launcher, tant qu'il est ouvert. Pour les jeux Steam, il reprend le compteur de Steam (tout ton historique) quand ta clé Steam Web API est renseignée. Tu le vois sur chaque jaquette, sur la fiche du jeu, et dans ton profil avec le classement « Les plus joués ». Nouveau tri « Plus joués » dans la bibliothèque.
- **En jeu** : une pastille cyan s'allume sur le jeu qui tourne en ce moment.
- **Alertes d'amis** : quand un ami Steam ou PlayStation se connecte ou lance un jeu, une carte apparaît dans Player X, ou une notification Windows si tu es ailleurs. Règle-les dans **Paramètres › Interface** (tout, seulement les jeux, ou aucune) et teste-les avec le bouton **Tester**.
- **Progression Battlefield 6** : Player X garde un relevé de tes stats chaque jour et dessine ta courbe de K/D, d'éliminations par minute et de victoires sur 7 jours, 30 jours ou depuis le début, avec ce que tu as fait sur la période. La courbe commence le jour où tu installes cette version.
- **Animations** : chiffres qui montent, barres qui se remplissent, courbe qui se dessine, cartes d'amis qui glissent. « Effets visuels » coupe les effets riches (les cartes d'amis gardent un glissé court), et « Réduire les animations » coupe tout mouvement.

- La fenêtre « Quoi de neuf » ne s'ouvre plus juste après la première installation.
- Page Stats : plusieurs corrections d'affichage et de cache.

## Installer

Télécharge `Player-X-Setup-0.5.0.exe` ci-dessous. Windows SmartScreen peut afficher un avertissement (installeur non signé) : **Informations complémentaires** puis **Exécuter quand même**.

Si tu as déjà la 0.4.0 ou plus récente, rien à faire : la mise à jour arrive toute seule.
